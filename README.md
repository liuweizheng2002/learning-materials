## 一、项目概览
这不是一个可以直接整体运行的单体项目，而是按课程章节沉淀下来的**学习资料集合**。内容以“**笔记 + 代码 + 数据/资料**”的形式组织，覆盖从 Python 语言进阶到大模型应用开发的完整学习路线。
本文重点说明：**仓库里有哪些文件、它们按什么规则摆放、每一类文件用什么方式打开**。文中路径均以仓库根目录为基准。
| 项目 | 说明 |
| --- | --- |
| 章节数量 | 8 个一级章节，按 `01`～`08` 编号 |
| 主要内容 | Python 进阶、数据分析、机器学习、深度学习、NLP、OpenCV、FastAPI、RAG |

## 三、文件组织规则（重点）
### 1. 两级编号目录
每个一级章节使用 `NN_章节名`，章节内部的知识点使用 `NN.小节名`：
```text
03_机器学习/
├── 01.机器学习论述/
├── 02.KUNN算法/
├── 03.线性回归/
└── ...
```
编号基本对应学习顺序，按名称排序即可获得推荐的阅读顺序。
### 2. 小节内部常见的子目录
不同章节的命名略有差异，但职责基本一致：
| 目录名示例 | 作用 | 常见文件 |
| --- | --- | --- |
| `01_代码`、`02_代码`、`04_代码`、`代码` | 课堂示例源码 | `01_xxx.py`、`main.py` |
| `02-笔记`、`2.笔记`、`01-笔记` | 知识点笔记 | `xxx.md`、`images/` |
| `03-代码`、`4.代码`、`5.代码` | 与笔记配套的代码 | `.py`、`.ipynb`、`.zip` |
| `3.数据` | 示例数据 | `.csv`、`.txt` |
| `06-资料` | 图片、数据等辅助材料 | `.png`、`.csv` |
| `images/`、`media/` | Markdown 笔记引用的配图 | `image-时间戳.png` |
| `项目物料` | 项目用到的静态资源 | 图片、模板等 |
> 记忆方法：**“笔记看 md，代码看 py/ipynb，数据看 csv，图示看 images”**。
### 3. 压缩包与解压目录成对出现
大量代码目录同时保留了 `.zip` 和同名解压目录，例如：
```text
01_代码/
├── day01.zip          # 打包备份，方便单独下载
└── day01/             # 解压后的目录，实际阅读和运行用这个
```
两者内容基本一致。**日常学习直接看目录即可**，不必再解压；`.zip` 可以理解为“课程原包/备份”。这也是仓库体积偏大的主要原因之一。
### 4. `day01/day01` 双层目录
部分 Python 基础章节存在同名嵌套：
```text
01_代码/day01/day01/01_定义汽车类.py
```
这是压缩包解压后多套了一层目录造成的，真正的源码在最内层 `day01/day01/` 中。
### 5. 笔记配图独立存放
Markdown 笔记旁边通常有 `images/` 或 `media/` 目录，图片名多为 `image-20240831102204286.png` 这种“时间戳”格式。移动或转载笔记时，需要连同图片目录一起移动，否则图片会失效。
### 6. 部分章节附思维导图
多个章节根目录放有 `.xmind` 文件：
- `01_Python进阶语言/Python进阶.xmind`
- `02_数据处理和统计分析/数据处理和统计分析.xmind`
- `03_机器学习/机器学习.xmind`
可用 XMind 或兼容软件打开，用来快速回顾知识框架。
### 7. 空文件与占位文件
例如 `08_RAG大模型开发/代码/AI大模型RAG与智能体开发/README.md` 是 **0 字节**的占位文件，没有实际内容；阅读时以各 `P1`～`P5` 子目录为准。

## 八、已知的文件层面现象
阅读时遇到以下情况不必困惑：
1. **压缩包与目录重复**：`.zip` 与同名目录并存，内容一致，优先看目录。
2. **同名双层目录**：如 `day01/day01/`，源码在最内层。
3. **目录名存在拼写差异**：`01.LINX基础`（Linux）、`02.KUNN算法`（KNN）、`05_NPL自然语言处理`（NLP）均为原文命名，引用路径时需保持一致。
4. **中文路径 + 空格 + 全角冒号**：`07_python WEB开发：fastapi实战`，脚本和命令行要加引号。
5. **`.DS_Store` 文件**：macOS 自动生成，出现在 `06_openCV图像处理/01.code/` 等目录，可忽略或删除。
6. **空 `README.md`**：`08_RAG大模型开发/代码/AI大模型RAG与智能体开发/README.md` 为 0 字节占位。
7. **Notebook 体积较大**：部分 `.ipynb` 内嵌了图片输出（最大约 1.7 MB），打开稍慢属正常。
8. **数据/模型缺失**：见第七节，属于有意排除，不是文件损坏。
9. **代码风格不统一**：同一知识点可能有多个版本（如学生管理系统的两套实现），以编号靠后/目录更完整的版本为准。
